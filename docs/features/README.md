# 機能一覧

## 概要

本システムは調剤薬局チェーン向けのシフト管理システムです。
複数店舗間の人員過不足をAM/PM別に可視化し、AIによる補填提案と応援要請・承認フローを提供します。

---

## 機能一覧

### シフト管理

- ユーザは、日別シフト画面で各店舗のAM/PM別過不足状況を確認できる
- ユーザは、月間一覧画面で1ヶ月分の全店舗の過不足状況を俯瞰できる
- ユーザは、CSVファイルから勤次郎のシフトデータをインポートできる

### AI補填提案・応援要請

- ユーザは、AI提案画面でAM/PM別の補填提案を確認できる
- 管理者（エリアマネージャー以上）は、AI提案から店舗へスタッフの応援要請を送信できる
- 店舗管理者以上は、自店舗スタッフへの応援要請を承認できる
- エリアマネージャー以上は、全店舗の応援要請を承認できる

### 店舗管理（CRUD）

- 管理者は、店舗を登録できる
- 管理者は、店舗情報を編集できる
- 管理者は、店舗を削除できる
- ユーザは、店舗一覧・詳細を閲覧できる
- 管理者（エリアマネージャー以上）は、店舗の曜日×AM/PM別必要人数を設定できる

### スタッフ管理（CRUD）

- 管理者は、スタッフを登録できる
- 管理者は、スタッフ情報を編集できる
- 管理者は、スタッフを削除できる
- ユーザは、スタッフ一覧・詳細を閲覧できる

### 認証・権限

- ユーザは、ログイン/ログアウトできる
- 権限に応じて操作可能な機能が制限される

## 画面一覧

| # | 画面名 | パス | 説明 |
|---|--------|------|------|
| 1 | ログイン | `/login` | 認証画面 |
| 2 | 日別シフト | `/shifts` | 店舗別AM/PM過不足表示 |
| 3 | 月間シフト一覧 | `/shifts/monthly` | 1ヶ月分の過不足カレンダー |
| 4 | AI補填提案 | `/shifts/suggestions` | AM/PM別の補填提案一覧 |
| 5 | 応援要請一覧 | `/support_requests` | 承認待ち要請の一覧・承認 |
| 6 | CSVインポート | `/imports/new` | 勤次郎CSVのアップロード |
| 7 | 店舗一覧 | `/stores` | 店舗リスト |
| 8 | 店舗詳細 | `/stores/:id` | 店舗情報の詳細 |
| 9 | 店舗登録 | `/stores/new` | 新規店舗の作成 |
| 10 | 店舗編集 | `/stores/:id/edit` | 店舗情報・必要人数の編集 |
| 11 | スタッフ一覧 | `/staffs` | スタッフリスト |
| 12 | スタッフ詳細 | `/staffs/:id` | スタッフ情報の詳細 |
| 13 | スタッフ登録 | `/staffs/new` | 新規スタッフの作成 |
| 14 | スタッフ編集 | `/staffs/:id/edit` | スタッフ情報の編集 |

**合計: 14画面**
